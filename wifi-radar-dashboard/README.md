# AuraSense — Wi-Fi 空間センシング・ダッシュボード

**カメラ・レンズ・映像なし。** Wi-Fi 電波の乱れ（CSI）から、人とモノ・姿勢・呼吸・転倒を「推定」するプライバシー保全型 空間AI のコンセプト実証ダッシュボード。

イルカのエコーロケーション（メロン器官）のように、空間に満ちる電波の反射から部屋の状態を把握する——それを既存の Wi-Fi でやる、という発想。

---

## できること

| 機能 | 内容 |
|------|------|
| 在/不在検知 | 「誰かいる」を CSI 振幅の変化で推定 |
| 動き検知 | 「動いている / 止まっている」を体動エネルギーで判定 |
| 姿勢推定 | 立位 / 着座 / 臥位 を反射プロファイルから分類 |
| 転倒検知 | 体動スパイク → 臥位 + 低体動 の連鎖を検知しアラート |
| 呼吸推定 | 胸郭の微動（0.13–0.55Hz）を FFT でピーク抽出 → rpm |
| 心拍推定 | 静止時の微小変調（0.75–2.0Hz）から bpm（確信度低め） |
| 人 vs モノ分類 | 周期的微動の有無で発光する「人型」と反射体「モノ」を分離 |
| シナリオ | 介護施設 / ホテル / 工場 / 家庭 の4モード |
| AI総評 | 現況の自然言語サマリ・時系列トレンド・将来予測・示唆 |

すべて **映像を記録せず、顔も撮らない**。

---

## 技術的実現性 — 本当に Wi-Fi でできるのか

**可能性は高い。** 市販 Wi-Fi は通信品質のため常時 **CSI (Channel State Information)** を測定しており、
人やモノが電波の多重反射（マルチパス）を乱すと CSI が変化する。これを AI で解くのが **Wi-Fi センシング**。

- **在/不在・動き**：CSI 分散で高精度検出 — 実装難易度 **低**
- **姿勢・転倒**：反射プロファイルの時間変化を分類 — **中**
- **呼吸**：胸郭 数mm の動きが CSI 位相を周期変調 — **中**
- **心拍**：~1Hz の微小変調、マルチアンテナ+高SNRで報告あり — **高**

### 研究の裏付け
- MIT CSAIL **RF-Pose**（電波で人体骨格推定）
- CMU **DensePose from WiFi**（Wi-Fi で人体表面推定）
- CSI ベースの呼吸・心拍推定論文群
- 標準化 **IEEE 802.11bf (WLAN Sensing)** — 電波センシングを Wi-Fi 規格に取り込む動き

本ダッシュボードは実機の代わりに、これらの物理現象を内蔵シミュレータで再現している。

## 構成

```
wifi-radar-dashboard/
├── index.html          レイアウト
├── css/style.css       スタイル（ドーム/グリッド床の世界観）
└── js/
    ├── dsp.js          FFT・特徴抽出（呼吸/心拍レート、体動エネルギー）
    ├── sim.js          CSI 物理シミュレーション（人・モノ・シナリオ）
    ├── infer.js        推論エンジン（状態推定・分類・転倒・アラート・総評）
    ├── render.js       Canvas 描画（アイソメトリック空間・信号波形・チャート）
    └── app.js          オーケストレーション（sim→dsp/infer→描画/UI）
```

依存ライブラリなし（vanilla JS + Canvas 2D）。`index.html` をブラウザで開くだけで動作。

---

## ローカル実行

```bash
# 任意の静的サーバで（file:// でも動きます）
python -m http.server 8000
# → http://localhost:8000/wifi-radar-dashboard/
```

## 位置づけ

> 「監視カメラを売る」のではなく、**映像を撮らない安全インフラ**を作る。
> これから伸びるのは顔認証AIではなく、プライバシーを残した空間AI。

介護＝転倒検知、ホテル＝在室確認、工場＝危険エリア検知、家庭＝高齢者見守り。
本デモはコンセプト実証（シミュレーション）であり、実機 CSI 取得層を差し替えれば実測データへ拡張できる設計。
